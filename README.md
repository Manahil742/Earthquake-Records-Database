# Earthquake-Records-Database
A relational database system designed to store, organize, and manage earthquake monitoring data using SQL and relational database concepts.

## Overview
The Earthquake Monitoring Database System is a Database Management System (DBMS) project developed to efficiently manage structured information related to earthquake monitoring.

The project focuses on designing a well-structured relational database that allows earthquake-related information to be stored systematically and retrieved through SQL queries. The database design uses entities, relationships, primary keys, foreign keys, and constraints to maintain data integrity and reduce data redundancy.

## Objectives

The main objectives of this project are to:

- Design a structured relational database for earthquake monitoring.
- Organize earthquake-related information into related tables.
- Establish relationships between different entities using primary and foreign keys.
- Maintain data consistency and integrity through database constraints.
- Write SQL queries for retrieving and analyzing stored information.
- Demonstrate practical implementation of database design and SQL concepts.

## Database Design

The database was designed using an Entity-Relationship (ER) model to represent the relationships between the different components of the earthquake monitoring system.

The design focuses on:

- Clearly defined entities and attributes
- Unique identification of records
- Relationships between related entities
- Primary and foreign key implementation
- Data integrity
- Reduction of unnecessary data redundancy

## Key Features

- Structured storage of earthquake monitoring information
- Relational database architecture
- Entity relationships using primary and foreign keys
- Data integrity through constraints
- SQL-based data retrieval and analysis
- Organized and normalized database structure
- Queries for filtering, sorting, joining, and analyzing data
